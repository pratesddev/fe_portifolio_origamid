# PORTIFÓLIO

**Site de portfólio profissional para apresentação de experiência, formação e contato de um desenvolvedor Front-end e designer UX/UI.**

---

## 📖 Sobre

- **O problema:** apresentar em um só lugar o perfil e as qualificações profissionais.
- **A solução:** uma página de portfólio com seções de apresentação, experiência, formação e contato.
- **Para quem:** profissionais de tecnologia e design que desejam apresentar seus trabalhos e informações profissionais.

---

## ✨ Funcionalidades

- [x] Apresentação do perfil profissional e da localização.
- [x] Navegação por âncoras para experiência, formação e contato.
- [x] Exibição de experiências, habilidades, formação, cursos e idiomas.
- [x] Informações de contato no rodapé.

---

## 🛠 Tecnologias

- HTML5
- CSS3

---

## 🚀 Começando

### Pré-requisitos

- Um navegador web atualizado.

### Executando

Abra o arquivo `index.html` em um navegador. Durante o desenvolvimento, também é possível usar a extensão Live Server no Visual Studio Code.

---

## 💻 Uso

Use os links no cabeçalho para acessar as seções de experiência, formação e contato. Consulte as informações profissionais e os dados de contato apresentados na página.
